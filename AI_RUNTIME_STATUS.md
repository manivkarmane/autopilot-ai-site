## Что реально протестировано на компьютере владельца
- Публичный Netlify-сайт доступен, демонстрационный сценарный помощник — резервная рабочая функция.
- WebGPU-вариант `/ai-lab.html` завершился ошибкой `Unable to find a compatible GPU`.
- CPU/WASM-вариант `/ai-cpu.html` завершился ошибкой `Error in input stream`.
- Точная первопричина второго сбоя не установлена: возможна загрузка модели/повреждённый кэш, сеть/включённый VPN/расширения, память или ошибка рантайма.
- **Работающая языковая модель не подтверждена. Нельзя обещать её клиентам.**
- На Netlify Drop файлы публикуются вручную. GitHub-коммит не меняет live-сайт автоматически.

## План без расходов и новой программы
1. Оставить стабильный сценарный режим `/demo-salon.html`, показать ответы по прайсу и передачу вопросов администратору.
2. При желании однократно попробовать запуск CPU-модели в Opera после отключения VPN для страницы, затем принудительно обновить страницу (Ctrl+F5). VPN отключать только на время теста и только если это приемлемо для владельца. При повторном сбое прекратить повторять скачивание ~512 МБ модели.
3. Не публиковать личные данные/номера клиентов в AI-тестах.
4. Для 24/7 автономного обслуживания нужна *отдельная* серверная схема или договорной ИИ-провайдер: стоимость, доступность из РФ, задержки, безопасность и обработку ПД нужно оценить до подключения.
5. Юридически корректная российская инфраструктура приема обращений, политика ПД и уведомление РКН, когда оно требуется, остаются незавершенными.
6. Следующая полезная задача — усилить сценарный продукт и провести 10–20 сценарных тестов, не тратя бюджет.
