# AUTOPILOT AI — шаблон внедрения для нового салона (v1)
Дата: 14.11.2026. Статус: рабочий чек-лист для демонстраций, НЕ коммерческая услуга.

## Подтверждено
- Профиль салона в расширенном демо можно скачать в JSON и загрузить обратно; владелец подтвердил успешный тест 14.11.2026.
- Сценарные ответы о цене, длительности и графике прошли тесты на вымышленных данных салона «Лотос».
- Сценарный бот правильно отказался подтверждать запись без календаря.
- Работа ИИ через CPU протестирована как отдельный эксперимент, но качество его ответов недостаточно для реальных клиентов.
- Никаких реальных персональных данных и платных услуг пока не подключено.

## Повторяемая настройка без программирования
1. Открыть `/demo-salon.html` на публичном Netlify-сайте.
2. Использовать только данные вымышленного салона при открытом публичном демо, пока не завершены юридическая подготовка и проверка условий сервиса.
3. Настроить название, график, адрес, цены услуг.
4. Скачать JSON-профиль, присвоить локально понятное название без персональных данных, например `demo-nails-moscow.json`.
5. Перезагрузить профиль из JSON и проверить, что поля восстановились.
6. Кнопкой проверки профиля прогнать тесты и вручную задать вопросы о стоимости, расписании, неизвестной услуге и записи.
7. Для коммерческой демонстрации показывать сценарные возможности, не обещая ИИ-автоматизацию 24/7 или запись в CRM.

## Технические и юридические ограничения
- JSON-файл не является защищённой клиентской базой, хранить в нём персональные данные нельзя.
- Профиль в демо не обновляет `/ai-cpu.html`, не заменяет серверную базу данных, не делает из демо мультитенантный SaaS.
- Для реальной записи нужны подключённый календарь/CRM, авторизация, журнал операций и тесты интеграций.
- Для коммерческого приёма заявок граждан РФ нужно завершить оценку локализации, безопасности, политики и уведомления Роскомнадзора при наличии обязанности.
- Публичная оферта не заменяет эти обязанности.
- Изменение GitHub-файлов не публикует Netlify Drop автоматически.

## Контроль владельца
Владелец подтверждает только: разрешение на реальные контакты, условия пилота, любые расходы свыше 0 ₽, договор/оферту и платежи. Техническую подготовку демо можно делать без платных сервисов.
