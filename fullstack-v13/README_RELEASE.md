# AUTOPILOT AI — единая разработческая сборка v13 (локальный full-stack sandbox)

**Статус: лабораторная сборка, НЕ коммерческий продукт и НЕ публичная версия.** 15.11.2026.

Этот архив объединяет **точную проверенную статическую версию v12.1** и **отдельный локальный серверный прототип v13**.

## Что реализовано сейчас

1. **Версия v12.1**: сохранены все 16 исходных файлов демосайта Studio, тесты и AI CPU.
2. **Серверная база SQLite**: сохранение профилей салонов и публикация цен для любого браузера, обращающегося к одному работающему серверу.
3. **Отдельные тестовые аккаунты**: логин и пароль для двух вымышленных салонов. Пароли с уникальной солью и PBKDF2, случайные сессионные токены только в HttpOnly cookie, проверка CSRF. Владелец одного салона не может изменить другой через API. **Не аудит безопасности и не полноценная система управления пользователями.**
4. **Учебный календарь**: выдача свободных интервалов с учётом длительности, атомарная резервировка с проверкой пересечений и разделением салонов. **Ни один слот не записывает реального клиента; входные поля не принимают имя, телефон или почту.**
5. **CRM-интерфейс**: есть безопасная точка подключения будущей CRM (`server/crm_adapter.py`), которая **намеренно запрещает** выдавать реальное подтверждение без интеграции.
6. **Локальная веб-панель**: `http://127.0.0.1:8765` (без дополнительного пакета Python).

## Чего НЕТ

- **Не подключена настоящая CRM**: для этого нужно выбрать CRM, получить разрешённый API-доступ, выяснить возможности и проверить операции в её тестовой среде.
- **Не опубликована общая серверная база в Интернете**: Netlify Drop по-прежнему размещает статический сайт. Сам Python/SQLite-модуль там не запускается. Устройства должны подключаться к одному доступному серверу для получения общих данных.
- **Не подключён существующий Studio v12.1 напрямую к серверному API**: это отдельный локальный серверный кабинет для проверки архитектуры. Старый Studio продолжает хранить настройки в браузере.
- Не проведены ни аудит инфраструктуры/безопасности, ни подготовка к обработке ПД. Нет способов восстановления аккаунта, MFA, серверных бэкапов, постоянного мониторинга, HTTPS и боевого размещения.

## Как попробовать на Windows (только на своём компьютере)

1. Установить Python 3.11+ с официального `https://www.python.org/downloads/`, если его ещё нет. Это не платный сервис.
2. Распаковать архив целиком в папку, например `AUTOPILOT_AI_v13`.
3. В папке двойным щелчком запустить `start_local_demo_windows.bat`.
4. В чёрном окне первый запуск выведет **два вымышленных логина и случайных пароля**. Сохранить их только локально, не отправлять в чат.
5. В Opera открыть `http://127.0.0.1:8765/` и войти одним из двух логинов.
6. Изменить цену, нажать «Сохранить черновик», затем «Опубликовать тестовые цены». В другом браузере на **этом же компьютере** открыть `http://127.0.0.1:8765/api/public/lotos` или `/romashka`.
7. Для учебной записи выбрать завтрашнюю дату, посмотреть свободные интервалы, создать одну учебную бронь. Повторное бронирование того же интервала сервер отклонит.

Если окно не открылось, проверьте наличие Python командой `py -3 --version` в Windows PowerShell.

## Проверка для разработчика

```sh
python -m unittest discover -s tests -p 'test_*.py' -v
node tests/test-core.js
node tests/test-store.js
```

Обычное развертывание, в том числе `netlify drop`, для полного архива **ЗАПРЕЩЕНО**: он содержит исходный код серверной части, который не предназначен для статического хостинга. Используйте v12.1 ZIP только для статического сайта и v13 локально для тестов серверной архитектуры.

## Перед промышленным запуском

- Выбрать хостинг с надёжным хранилищем, TLS/HTTPS, резервированием и достаточными лимитами; предварительно согласовать расходы, если они больше 0 ₽.
- Подготовить защищённую реализацию авторизации и секретов с аудитом, контроль ресурсов, мониторинг, обновления и резервное копирование.
- Интегрировать Studio с API и протестировать на двух независимых устройствах.
- Определиться с CRM и реализовать adapter + журнал операций с безопасным подтверждением брони.
- До любых ПД граждан РФ проверить и выполнить правовые требования, включая локализацию, основания обработки, политику, договоры и уведомление РКН при наличии обязанности. Черновик Яндекс Форм пока не публиковать.

Расходы на подготовку этого архива: **0 ₽**. Это не означает, что промышленный сервер будет работать без затрат.

### Проверки и ограничения

10 серверных тестов проходят. Попытка запустить полноценное браузерное E2E с локальным адресом в автоматической среде закончилась `net::ERR_BLOCKED_BY_ADMINISTRATOR`; качество UI на устройстве владельца ещё не проверено. Отдельная лабораторная ветка GitHub содержит выпускные инструкции и скрипт контрольных сумм для переноса v12.1, но НЕ весь исходный код v13. Попытка импорта публично развёрнутых файлов v12.1 выявила несовпадение SHA-256 файла `ai-cpu.html` с проверенным архивом, поэтому импорт справедливо остановлен. Каноническим исходником v12.1 пока остаётся ZIP внутри v13.
