# AUTOPILOT AI — запуск в России

## Текущий статус
Сайт-демонстрация и сценарный чат готовы. Ранее протестирована заявка через Netlify Forms, но для нового рынка России сбор персональных данных через зарубежную форму приостановлен в коде сайта до проверки соответствия законодательству.

## Важно: обновление сайта
Код обновлён в GitHub. Но существующий сайт на Netlify Drop загружается вручную и **не обновляется автоматически при изменении GitHub**. Для публикации безопасной версии загрузите архив autopilot_ai_ru_safe.zip в существующий проект Netlify. Проверяйте публичную страницу, а не наличие старой формы в панели Netlify.

## План
1. Подтвердить статус владельца (самозанятый, ИП, ООО) и реквизиты оператора данных.
2. Проверить применимость НПД (самозанятости) именно к оказываемой услуге: установка и обслуживание собственного ИИ-решения, без перепродажи чужого ПО и найма работников.
3. Настроить хранение/обработку заявок с соблюдением требований к персональным данным граждан РФ (152-ФЗ, редакция с 01.07.2025).
4. Подготовить сведения об операторе, политику обработки данных, согласие при необходимости и уведомление в Роскомнадзор, если требуется.
5. Протестировать российскую форму на собственных данных.
6. Подготовить пилот и тестировать спрос через разрешённые каналы, без несогласованной рекламной рассылки.
