# AUTOPILOT AI — статический сайт, версия 3

Сайт содержит интерактивную демонстрацию (НЕ настоящий ИИ), калькулятор,
предварительный тариф и HTML-форму заявки на пилот.

## Опубликование на уже созданном сайте Netlify
1. В Netlify откройте свой сайт и раздел **Forms** → **Enable form detection**.
2. Для обновления уже опубликованного сайта откройте вкладку **Deploys**,
   найдите ручную загрузку («Drag and drop») и перетащите этот ZIP либо папку,
   содержащую `index.html` и `thank-you.html`.
3. После деплоя проверьте, что форма **pilot-request** появилась в Forms.
4. Сделайте одну тестовую заявку с собственной рабочей почтой и проверьте
   вкладку Forms → Verified submissions. Не отправляйте тестовые персональные
   данные других людей.
5. При необходимости включите уведомления на почту в Forms → Notifications.
6. Тестовая заявка не подтверждает готовность бизнес-сервиса: ИИ, CRM,
   автоматическая запись, рассылка и платежи ещё не работают.

## Безопасность и правовые требования
Для коммерческого приёма заявок необходимо определить юридическое лицо или
самозанятого/ИП (в применимой юрисдикции), оператора персональных данных,
контакт для запросов об удалении данных и опубликовать актуальную политику
обработки данных. До этого используйте форму лишь для собственных тестов.
Не размещайте API-ключи и пароли в публичном репозитории.
