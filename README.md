# AUTOPILOT AI — размещение без затрат на хостинг

**Статус:** демонстрационная версия; это ещё не работающий ИИ-сервис.
Чат отвечает на заранее подготовленные вопросы. Нет интеграции с ИИ, календарём,
оплатой, рассылкой и базой реальных клиентов.

## Публикация
1. Подключите GitHub официальным приложением к ChatGPT. Пароли и токены не пересылайте.
2. Загрузите `index.html` в корень репозитория `autopilot-ai-site`.
3. Создайте бесплатный аккаунт на https://dash.cloudflare.com/ .
4. В Cloudflare выберите Workers & Pages → Create → Pages → Connect to Git.
5. Разрешите доступ к *этому* репозиторию.
6. Выберите статический сайт без команды сборки, выходная директория — корень репозитория.
7. Нажмите Deploy и проверьте адрес формата `имя.pages.dev`.

**Почему не GitHub Pages:** GitHub запрещает использовать GitHub Pages
как бесплатный хостинг для запуска коммерческого SaaS или онлайн-бизнеса.
GitHub здесь нужен для хранения кода; Cloudflare Pages — для публикации.

## Ограничения
Публично не размещайте API-ключи, пароли и персональные данные.
Реальные заявки, оплата и ИИ-помощник требуют отдельной настройки,
юридических документов и проверки условий провайдеров.
Расходы на статический хостинг в рамках бесплатных лимитов: 0 ₽.
